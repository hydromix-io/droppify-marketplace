# Limitaciones

El conector apunta a https://mcp.hydromix.io/mcp (producción). La clave de licencia nunca viaja en el ZIP ni en el catálogo: se introduce por el usuario (license_key del plugin o cabecera x-api-key del conector). @Droppy no ofrece autocompletado: usa /droppy:<skill> solo si el cliente lo muestra o lenguaje natural, sin workaround. Desktop no recibe hooks; Claude Code solo los recibe mediante --hooks explícito. Shopify solo aparece con --shopify-mcp-name.
