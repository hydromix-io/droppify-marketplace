# Términos de uso

Droppy ofrece análisis y propuestas para dropshipping Shopify en la UE. Las acciones sensibles requieren aprobación individual y autorización server-side; no se garantizan resultados comerciales. Droppy MCP aplica licencia, plan, límites y auditoría cuando está autorizado, pero la ejecución externa queda fuera de su control. Esta entrega usa un fixture no productivo y requiere configuración manual; no incluye setup automático 18.x ni permisos implícitos.
