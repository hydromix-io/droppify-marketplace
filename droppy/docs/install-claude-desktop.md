# Instalación en Claude Desktop

Añade el marketplace por URL (Customize > Plugins > Add > Add marketplace) e instala Droppy desde el Directorio > Organización. El plugin trae el conector Droppy MCP preconfigurado hacia https://mcp.hydromix.io/mcp; pega tu clave de licencia en el campo license_key del plugin (o en la cabecera x-api-key del conector) y autorízalo. Instalar el plugin no conecta OAuth. Desktop no incluye hooks.
